# Exercises

## Exercise 1, turn a deck into a video (~8 min)

1. Open tinyurl.com/EHS-AI and copy the practice deck (File > Make a copy).
2. In Slides, choose File > Turn into video.
3. Keep "Include AI voiceover, script, background music and animation" switched on.
4. Fix one thing in the script for scene 1.
5. Hit Update, then play the scene.

**Stretch:** change the voice or the language.
